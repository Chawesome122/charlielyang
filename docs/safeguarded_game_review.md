# Safeguarded accelerated policy search: executed negative-beta robustness

This extension addresses blueprint §8.6's instruction to diagnose unsuccessful iterations and try a justified different search method. It does not alter the four-state law, payoffs, upwind generator, linear solver, global unilateral maximizer or original Nash acceptance criteria. All parameters remain the original hypothetical `adaptation_negative` scenario, with both betas −0.7. The information freeze remains 2026-10-11; these are numerical experiments, not new empirical observations or forecasts.

## Method and registration

`src/weaponized/game/safeguarded_iteration.py` implements a separately named Type-II Anderson multisecant search on the **evaluated global Hamiltonian best-response residual**. At each bounded policy pair `z=(u,c)`, the original `evaluate_policies` solves the two discounted policy-evaluation equations, and the original `policy_deviation_gaps` supplies exact global maximizers across both pipeline-drift branches. Write this response map as `T(z)` and residual `r(z)=T(z)-z`. A root still has to meet every original criterion; a statewise response by itself is not the full-game solution.

From recent policy/residual differences, the accelerated proposal is

`z_new = projection_box[z + omega*r - (DeltaZ + omega*DeltaR)*gamma]`,

where `gamma` solves regularized least squares against the residual, using a small dense Gram system with relative Tikhonov regularization. Box projection only makes a trial admissible. Every trial is freshly policy-evaluated, and backtracking accepts a decrease in the registered search merit. A relaxed unaccelerated global-response direction is tried if the accelerated direction fails. If no evaluated direction decreases merit, the method stops `not_solved`, retaining the best actual arrays. Search merit is not the acceptance statistic. There is no theorem here that this general-sum map is contractive or that Anderson converges.

Three registries were created before their corresponding execution families:

- `configs/safeguarded_game.yaml`: three starts (zero/one/seeded smooth random), 7 and 17 nodes per dimension, six-vector history, damping 0.8, infinity-type global residual merit.
- `configs/safeguarded_game_rms.yaml`: the same three 17-node starts, with RMS residual merit, aligned with the least-squares acceleration. Final tests still use global maxima.
- `configs/safeguarded_game_coarse.yaml`: three 17-node starts interpolated from the verified 7-node candidates, twelve-vector history, damping 1, RMS search merit and smaller fallback steps. Source archive hashes are pinned and checked; no coarse values are mistaken for re-evaluated fine-grid values.

All retain gain ≤1e-8, action error ≤1e-7, policy-evaluation residual ≤1e-8*(1+flow-payoff norm), and original linear rtol 1e-11. The direct search uses the two unilateral maximizers rather than repeatedly solving the original 25-status simultaneous action enumeration. Only the iteration map changes.

`configs/safeguarded_reference_sources.json` pins the unchanged original HJB/model/policy helpers, base parameters and final new numerical/audit/runner sources. The runner refuses source substitutions or changed acceptance criteria. All final twelve attempt records contain the same final numerical-method source hash. Initial executed API versions and their exact arrays, JSON, logs and source snapshots are retained separately under `outputs/scenario/safeguarded_initial_execution/`; these are historical attempts, not an additional independent twelve-observation sample. Their preservation manifest records exact bytes. Final current-source attempts are generated by the commands below.

## Results and limitations

The final experiment comprises **12 registered attempts**: three accepted **7^4=2,401-node finite-grid candidates**, and **nine unsuccessful 17^4=83,521-node attempts**. All nine fine-grid searches stop because no tested residual-decreasing direction is found. The infinity-merit zero start has global gain approximately 5.18e-9, already below the gain threshold, but action error approximately 1.02e-4, above 1e-7. The RMS and coarse-interpolation attempts likewise do not satisfy the action criterion. Small linear residuals and gains cannot substitute for that criterion. Consult the generated CSVs for exact executed values/runtimes.

This extends the evidence about numerical difficulty without claiming to solve it. It does not show equilibrium nonexistence. Piecewise continuation derivatives can create a nonconcave kink at an action equal to its pipeline state; branch switches are a genuine feature of this finite-grid maximization. The original deterministic argmax also measures action distance to one selected maximizer rather than the whole best-response set when there are exact ties. This extension preserves that convention for comparability and does not reinterpret a failed action test as success. No 21-node extension is justified as a successful refinement of a missing 17-node candidate.

The three coarse candidates do not certify continuum equilibrium, uniqueness, empirical calibration or actual strategic behavior. Runtime comparisons with longer failed original runs would not establish a convergence speedup, because stopping rules and executed work differ. Numerical outcomes remain physically separate from empirical data.

## Execution, tests and audit

```bash
OPENBLAS_NUM_THREADS=1 uv run python scripts/run_safeguarded_game.py
OPENBLAS_NUM_THREADS=1 uv run python scripts/run_safeguarded_game.py --registry configs/safeguarded_game_rms.yaml --out outputs/scenario/safeguarded_game_rms
OPENBLAS_NUM_THREADS=1 uv run python scripts/run_safeguarded_game.py --registry configs/safeguarded_game_coarse.yaml --out outputs/scenario/safeguarded_game_coarse
uv run python scripts/audit_game.py --out outputs/scenario/safeguarded_game
uv run python scripts/audit_game.py --out outputs/scenario/safeguarded_game_rms
uv run python scripts/audit_game.py --out outputs/scenario/safeguarded_game_coarse
uv run python scripts/analyze_safeguarded_game.py
uv run pytest -q tests/test_safeguarded_iteration.py
```

Run the three registered solve commands in that order so the verified coarse warm-start archives exist. The default reporting path can independently audit and analyze the saved arrays; `--full` replication should execute the solves as well. An archive/status validation pass means the actual accepted/failed classifications were reproduced, not that all numerical attempts met Nash conditions.

Ten focused tests execute the scalar multisecant root, bounded update, independent original-HJB residual map, exact zero-response finite-grid recovery, budget failure, false accepted labels, stale values, invalid statuses/nonfinite fields, corrupted NPZ bytes, substituted axes and modified-source rejection. Original numerical-core files remain unchanged. `src/weaponized/game/safeguarded_archive.py` hashes and decodes the same NPZ byte snapshot, separately re-forms the original generator/payoffs and rechecks each global criterion.

Outputs: `outputs/scenario/safeguarded_analysis/analysis.json`, `attempts.csv`, `iteration_history.csv`, `archive_integrity.csv`, `summary_table.csv`, `scenario_table.tex`, `convergence.pdf/png`; each family has per-attempt NPZ/JSON plus the original independent audit. Exact command logs and the focused test result are under `outputs/diagnostics/safeguarded_*`.

A further independent root audit, `scripts/review_safeguarded_independent.py`, uses the unchanged original generator/payoffs/global maximizers rather than the new audit helper, reconstructs all initial and coarse-interpolated policies, and verifies all current source snapshots. Its 89 checks passed for the twelve final attempts, retaining three coarse acceptances and zero fine acceptances. Numerical source snapshots left over from initial versions were relabeled/replaced in current directories with the actual final-source copies, while the original copies remain preserved in the initial-execution archive. No earlier hash was silently rewritten to claim a different execution.
